# 手動 SVG 補丁庫 (Override & Merge)

此目錄用於存放手動修正的缺漏字與港標字形補丁。系統會在編譯時自動優先載入此處的 JSON。

## 檔案命名規範
支援以下兩種命名方式：
1. **單一漢字**：例如 `羣.json`
2. **Unicode Hex**：例如 `7FA3.json`

## Schema 定義
補丁必須是嚴格的 JSON 格式，並支援審查標記以解除前端「未驗證」警告：

```json
{
  "strokes": [
    "M500,200 Q450,300 480,400", 
    "M600,300 Q650,400 680,500"
  ],
  "medians": [
    [[500, 200], [480, 250], [450, 300]],
    [[600, 300], [640, 350], [680, 400]]
  ],
  "reviewedBy": "expert-001",
  "reviewedAt": "2026-10-15",
  "standard": "HK-EDB-2024"
}
